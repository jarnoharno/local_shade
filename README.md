This repository contains the code for the Local Shade backend.
Local Shade is a classification service with different levels of abstraction for classifying different regions of a city based on the events held there.

## Local Operator UI

A modern, futuristic UI for the Local Operator project. This UI is designed to provide a clean, intuitive interface for interacting with AI agents.

### Features

- Dark theme with neon green accents
- Interactive chat interface
- Agent role selection
- Tool integration (unified API, memory, llm, tools)
- Responsive design for all screen sizes

### Getting Started

1. Open `index.html` in your browser

### Usage

- Click on "You are a..." to cycle through different agent roles
- Type messages in the chat input and press Enter or click the send button
- Click on the footer items to activate different tools

### Customization

You can customize the UI by modifying the CSS variables in `styles.css`.
