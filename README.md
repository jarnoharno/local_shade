# Local Shade

This repository contains the code for the Local Shade backend and UI.
Local Shade is a classification service with different levels of abstraction for classifying different regions of a city based on the events held there.

## Backend

The backend provides the core functionality for the Local Shade service, including:
- Data processing and classification
- API endpoints for accessing the service
- Database management

## UI

The repository now includes a modern, futuristic UI for interacting with the Local Shade service:

### Features

- **Dark Theme with Neon Accents**: Modern dark theme with neon green accents for a futuristic look
- **Agent Role Selection**: Easily switch between different agent roles
- **Chat Interface**: Clean chat interface for interacting with the AI
- **Tool Selection**: Quick access to different tools via the footer
- **Responsive Design**: Works on desktop and mobile devices

### Getting Started with the UI

1. Open `index.html` in your browser
2. Use the chat interface to interact with the service
3. Explore different tools using the footer navigation

### Customization

You can easily customize the UI by:
- Modifying the CSS variables in `styles.css` to change colors and styling
- Adding new tools to the footer
- Extending the JavaScript functionality in `script.js`
